## 기획 → 수정 → 재검수

사용자 캡처 8건과 검정 마케팅·서비스 모션 요청을 [PLAN.md](PLAN.md)에 정리한 뒤 구현했다. 기존 v05의 서비스 가격·수량·계약 기준과 정보 순서를 유지했다. 검정/보라의 기존 시각 체계를 사용하고 imagegen과 product-design:audit 스킬을 적용했다. 기존 벤치마킹 및 사업 근거는 `../review-v05/PLAN.md`에 보존했다.

1. 중앙 정렬·카피·웹툰 기준·진행 제목을 먼저 수정했다.
2. 서비스별 새 이미지 14종을 생성하고 마케팅·개발 모션과 검정 배경을 적용했다.
3. 실제 화면 재검수 중 영상 상세의 같은 이미지 3회 반복을 발견했다. 현재 서비스와 관련 서비스의 서로 다른 새 제작 예시 3개로 바꾸고 각 상세 링크를 연결했다. 웹툰 FAQ에도 이미지 1장 기준을 명시했다.
4. 최종 코드로 lint·테스트·빌드·공개 경로 검사와 브라우저 반응형 검수를 완료했다.

## 이미지와 보존

- `public/creative-v06/`: 웹용 WebP 14개, 합계 2,611,268바이트.
- `generated-originals/`: 생성 PNG 원본 14개. 이전 이미지도 삭제하지 않았다.
- `image-prompts.json`: 실제 생성 프롬프트와 도구 결과 경로.
- `image-manifest.json`: 원본·웹 파일 매핑, 크기, SHA-256.
- `prepare-assets.mjs`: 원본 복사와 전체 이미지 WebP 변환. 합성·부분 편집·자르기 없음.
- 생성 이미지는 제작 방향 예시로 표시하며 고객 실적이나 실제 성과 자료로 제시하지 않는다.
