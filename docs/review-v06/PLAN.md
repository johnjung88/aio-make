## 이번 결정

사용자 화면 의견 8건을 기준으로 기존 화면을 수정한다. 마케팅은 영상·개발과 같은 검정 배경으로 통일하고, 마케팅·개발 메인 및 8개 상세에 서비스의 작업 흐름을 보여주는 모션을 넣는다. 가격·계약·서비스 경로는 유지한다.

1. 회사소개 첫 화면 전체와 세 분야 소개 제목을 중앙 배치한다. 설명을 좌우로 나누던 그리드는 세로로 묶는다.
2. 메인 제작 과정은 ‘AI로 효율을 높이고 / 전문가가 품질을 지킵니다’를 자연스러운 띄어쓰기와 줄별 중앙 정렬로 바꾼다. 양끝 강제 정렬을 제거한다.
3. 작업 기준 카피는 영상·마케팅·개발 모두에 맞게 ‘만드는 일의 끝은, / 고객이 쓰기 시작하는 순간입니다’로 바꾼다. 실제 사용과 인계를 강조한다.
4. 제작 방향 레퍼런스 14개(영상 6·마케팅 4·개발 4)는 서비스별 새 생성 이미지를 만든다. 특히 마케팅의 도식과 개발의 기존 화면 캡처를 모두 교체한다. 실제 고객 CMS 사례는 보존하고 예시만 교체한다. 과거 이미지도 보존한다.
5. 웹툰은 사용자가 확정한 ‘1억의 구단주 납품 이미지 1개 = 1컷’으로 고친다. 내부 패널로 자른 이전 해석을 철회한다. 전체 이미지가 PC·모바일 프레임에 동시에 보이고, 분량 비교의 10/20/30 단위도 이미지 개수를 뜻하도록 설명한다. 확정되지 않은 고정 회차 판매조건은 만들지 않는다.
6. 영상 서비스의 진행 과정 제목에서 sticky를 제거해 스크롤 중 단계와 겹치지 않게 한다. 867px·모바일·데스크톱에서 확인한다.
7. 마케팅 홈·상세는 검정 바탕/보라 강조/밝은 본문으로 통일한다. 새 이미지와 모션이 중심이 되고 가격·범위는 충분한 대비로 읽히게 한다.
8. 모션은 새 생성 이미지를 이용한 장면 전환과 서비스별 4단계 흐름을 결합한다. 마케팅은 제작→채널→반응, 개발은 설계→구현→사용을 설명한다. 가짜 실적·성과 수치를 쓰지 않는다. 일시정지 버튼, 화면 밖 정지, 브라우저 동작 줄이기 설정을 지원한다.

## 제작·검수 순서

사용자 캡처 및 현재 렌더 확인 → 이 계획 기록 → 이미지 생성/저장 → 우선 텍스트·정렬·웹툰·sticky 수정 → 검정 마케팅·서비스 모션 구현 → 브라우저 재검수 → 발견 결함 수정 → 빌드/회귀 확인.

화면 폭 360/390/867/1440px에서 넘침·이미지 비율·제목·선택 탭·버튼을 확인한다. 모션은 시작/정지/다시 재생, 페이지 이동, 화면 밖 정지 및 동작 줄이기 스타일을 확인한다. 웹툰은 PC와 모바일 프레임에서 같은 전체 원본이 보이고 1컷 설명이 일치하는지 검수한다. 전체 공개 경로·링크와 타입·lint·기존 단위 테스트·빌드를 확인한다.

## 스킬·범위

imagegen 기본 도구로 이미지를 생성하고 원본/웹용 파일과 프롬프트를 보존한다. product-design:audit의 실제 화면 증거 기준으로 검수한다. 기존 제품의 검정/보라 색상과 한국어 서체를 따른다. 추가 라이브러리나 유료 영상 서비스는 도입하지 않는다.
