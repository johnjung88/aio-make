# 디자인 비교 v01

범위: 같은 실제 문구, 메인·마케팅 상세, 1440px/390px, 각 1회 캡처. 브라우저 자동 검증과 Codex 시각 점검을 구분했다.

| 기준 | A: 녹색·좌우 구성 | B: 파란색·중앙 구성 |
|---|---|---|
| 서비스 이해 | 첫 화면에서 서비스 설명과 월간 흐름을 나란히 읽음 | 메시지는 크게 보이나 흐름 카드가 아래로 이동 |
| 신뢰감 | 차분한 배경과 조건 중심 정보 | 보다 제품 소개에 가까운 밝은 카드 구성 |
| 가독성 | 짧은 줄과 섹션 간 간격 | 중앙 제목은 강조되나 첫 화면 길이가 늘어남 |
| 가격 조건 | 동일한 순번 표·보장기간·해지/갱신 설명 | 동일 내용·표 구조 |
| 상담 편의 | 첫 화면 설명 다음 CTA | CTA 위치는 명확하나 전체 세로 길이가 더 김 |

기본 후보는 A. 메인 CTA를 빠르게 찾고 서비스 운영 흐름을 같이 읽을 수 있다는 판단이다. 정량 사용자 시험 결과가 아니라 자체 비교다. B도 비공개 미리보기에서 유지한다.

규칙: 밝은 미색 배경, 짙은 녹색 본문, 녹색 CTA, 1176px 내용 폭, 22~32px 모바일/데스크톱 여백, 1열 모바일 카드, 접근 가능한 폼 라벨·포커스, 가로 스크롤 없는 390px 화면. 30·60·90만원만 단독 강조하지 않고 적용 순번·보장기간·VAT·별도 비용을 같은 섹션에 표시한다.

사례 이미지처럼 보이는 실제 고객 사진이나 수치는 만들지 않았다. 프로젝트 카드의 색면·제목은 시각 구분용이며 산출물 샘플로 표시하지 않는다.
