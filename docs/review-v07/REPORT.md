## 실제 검증

- 로컬 브라우저에서 메인·회사소개·영상·마케팅·개발·웹사이트 서비스 상세의 문구와 화면을 확인했다. 390px 모바일 및 기본 브라우저 폭에서 수정한 문구의 줄바꿈과 중앙 정렬을 재확인했다. 실제 모바일 기기 검증과 구분한다.
- `npm run lint` 통과. `npm run build` 통과. 16개 테스트는 Node 파일 동시 실행에서 DB 테스트 하나가 원인 메시지 없이 실패했고, DB 단독 실행과 `--test-concurrency=1` 전체 재실행에서는 모두 통과했다.
- GA4 Google Cloud 프로젝트 `aio-make-analytics`의 Data API가 사용 설정됨을 화면에서 확인했다. 속성 `536780274`의 기존 Viewer 서비스 계정용 JSON을 사용자 직접 생성 후 전달된 로컬 파일로 확인했다.
- 키 내용을 출력하거나 Git에 넣지 않고, 해시가 일치하는 사본을 `I:\AIO_OS\08_RUNTIME\MAIN-01\aio-make\credentials\ga4-service-account.json`에 두고 현 사용자와 SYSTEM만 파일 접근을 허용했다. `.env.local`에 서버 전용 파일 경로를 연결했다. `.env.local`은 Git 제외다.
- 로컬 관리자 로그인 API 성공. 관리자 GA4 API의 7·28·90일 실제 조회가 모두 HTTP 200, `connected=true`였고 일별 행은 각각 7·28·90개였다. Google Analytics UI의 지난 7일 활성 사용자와 API 지난 7일 수치도 일치했다.
- 사용자 로그인 후 로컬 관리자 브라우저에서 대시보드 `GA4 연결됨`, 방문·문의 통계의 최근 7·28·90일 기간 전환과 수치·일별 추이 표시, 연결 상태의 `방문 통계가 연결됐습니다`를 확인했다. 활성 사용자는 각각 5·31·93명으로 앞서 확인한 API 결과와 일치했다.

## 구분과 남은 확인

- 관리자 화면에서 문의·콘텐츠 저장소는 `연결 대기`로 표시됐다. GA4 연결 완료와 별개로 Supabase 운영 데이터 연결은 미완료다.
- Google Cloud 연결은 이 로컬 작업트리에 적용됐다. Vercel 운영 환경 변수·배포는 아직 적용하지 않았다. 운영 사이트의 GA4 수집·중복 페이지뷰, Supabase와 운영 관리자 동선도 별도 검증이 필요하다.
- 사용자가 다운로드한 원본 JSON은 원래 OneDrive 하위 다운로드 폴더에 남아 있다. 승인 없이 삭제하거나 이동하지 않았다. 클라우드 동기화 여부 확인 후 별도 정리해야 한다.
- 기존 v06 및 이전 검수 기록과 이미지 원본은 보존한다. push·PR·운영 배포 없음. 사용자 최종 승인이나 독립 AI 검토로 표시하지 않는다.
