## GA4 실제 적용 상태

사용자가 승인한 범위 안에서 다음 상태를 Google UI에서 확인했다.

- 이미 존재하던 Cloud 프로젝트: **AIO MAKE Analytics / aio-make-analytics**. 이번 작업에서 프로젝트 자체를 새로 만들었다고 기록하지 않는다.
- 전용 서비스 계정 생성: `aio-make-dashboard@aio-make-analytics.iam.gserviceaccount.com`.
- AIO-MAKE GA4 속성 **536780274**에 **뷰어** 권한 적용 완료. Google 프로젝트의 추가 IAM 역할은 부여하지 않았다.
- Analytics Data API는 활성화 버튼 단계다. 이 버튼에 Google API 이용약관 동의가 포함되어 사용자에게 해당 동의를 별도로 요청했다.
- JSON 인증 파일 생성 창을 준비했다. 브라우저 도구의 인증 정보 변경 규칙에 따라 최종 생성·다운로드는 사용자에게 인계했다. 파일은 아직 앱 서버에 연결하지 않았다.
- **실제 Data API 성공 응답, 실제 7/28/90일 통계와 관리자 화면 대조는 아직 미검증**이다. 뷰어 권한만으로 통계 연동 완료라고 표시하지 않는다.

관리자 화면과 서버 조회 구현은 v04의 7/28/90일·이전 기간·일별 추이·채널·페이지·기기·연결 진단을 유지한다. 키나 개인 계정 정보는 Git에 추가하지 않았다. Google 권한 확인 캡처는 Git 제외 `.qa`에만 보관했다.
