## 수정 이유

R3는 실제 작업물과 구매 판단 정보를 보강했지만 서비스 화면을 정적인 설명과 카드 위주로 정리해 사용자가 요청한 레퍼런스의 공간 전환과 개별 요소 리듬을 충분히 반영하지 못했다

검정 공통 배경과 안정된 본문은 유지하고 실제 작업물을 탐색하는 React 상태 전환, 스크롤 진행과 연동된 장면, 느린 자동 레일을 서비스별로 구현한다

## 고정 조건과 완료 기준

- 실제 작업물과 기존 권리·리뷰 게이트 유지, 허구 성과·계정·게시물 추가 없음
- AI 계정 수는 최신 사용자 확정대로 4개
- 가격 정본, FAQ 바로 위 사례, 컨텐츠 내부 상세 링크, 동일 CTA 정렬 유지
- 본문은 이동시키지 않고 문장 끝 마침표 금지 유지
- 자동 영상은 muted·playsInline·가시 활성 1개만 재생하며 이탈과 숨김 탭에서 pause
- reduced motion·자동재생 거부 시 완성 포스터와 원본 보기·기본 영상 조작 유지
- reduced motion에서 정보가 숨겨지지 않고 수동 탭은 즉시 전환
- 스크롤은 passive + 단일 rAF 예약 + 정리 함수, 진행값은 CSS 변수에 직접 기록
- 라이브러리 설치·이미지 생성·업로드 없음, 원본·기존 파생 컷 보존
- 3213·3214·3215 미리보기 보호, 빌드·브라우저는 독립 검증자 한 명만 실행

구현 소유는 `components/content-site/services/**`와 `lib/content-site/services/**`이며 홈 모션과 공통 셸은 A 담당이다
