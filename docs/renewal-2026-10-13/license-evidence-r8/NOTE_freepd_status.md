# FreePD 사이트 상태와 출처 설명 (2026-10-16)

- 현재 https://freepd.com/ 는 "FreePD.com - Site Closed ... permanently closed. 2008-2025" 안내만 표시한다 (`freepd_live_site_closed_2026-10-15.html`, HTTP 200 / 곡 목록은 404).
- 따라서 라이선스 선언·곡 목록·mp3는 Wayback Machine(web.archive.org)의 freepd.com 사본과 Internet Archive 항목 archive.org/details/freepd (`ia_freepd_item_metadata.json`, 익명 업로더가 2022-03-18에 올린 사본)로 확인했다. 채택한 8곡은 Wayback의 freepd.com/music/*.mp3 사본이며 크기와 MD5가 IA 항목과 같다(TRACK_EVIDENCE_freepd_extracts.md).
- FreePD 선언(`freepd_wayback_home_20241231.html`): "This music is all licensed CC0 1.0 Universal Public Domain Dedication.", 광고 사용 "Can I use this music in an ad? Yes", YouTube/Facebook/Twitch "Yes", 크레딧 "Must I credit the musician in my film? Nope - but we do like it."
- 법적 한계: FreePD 법률 페이지(`freepd_wayback_legal_20241225.html`)는 "You can't just 'declare' something is Public Domain"이라며 변호사 상담을 권한다. 곡별 CC0 근거는 FreePD의 선언이며, 작곡가 본인 사이트는 같은 곡을 CC BY로 배포하는 경우가 있다(예: Kevin MacLeod는 incompetech에서 CC BY 4.0, 근거 `../license-evidence-r7/music_incompetech_faq_webfetch_excerpt.md`). 같은 곡이 두 라이선스로 공개된 것이라 CC0 사본을 받은 사람은 CC0를 쓸 수 있지만, 완전한 무위험은 아니다.
- 완화책: 사이트 푸터에 자발적 크레딧 한 줄(예: "Music: Kevin MacLeod, Bryan Teoh, Rafael Krux via FreePD (CC0)")을 두면 크레딧 의무가 어느 쪽으로 해석되어도 대응된다. 의무는 아니다.
