2026-10-14 · 공통 규칙·토큰·블록·테스트·완료 기준은 `BRIEF_P2R.md`가 정본이다. 이 문서는 서비스마다 다른 것(첫 화면, 고유 섹션, 미디어, 카피 초안, 과정·범위·FAQ, SEO)만 정한다. 카피는 초안이다. 다듬어도 되지만 `BRIEF_P2R.md` 6-1 규칙(테스트로 강제)을 지키고 고친 내역을 RESULT에 적는다.

## 0. 공통 골격과 공통 문구

### 0-1. 섹션 순서 (서비스 페이지 전체 공통)
`hero` → `types` → `signature`(서비스마다 1~2개) → `works`(검토 빌드에서만) → `pricing` → `process` → `scope` → `faq` → `inquiry` → `related`

광고로 들어온 방문자가 첫 화면에서 볼 것: 무엇을 만드는지(h1·lead), 얼마부터인지(가격 칩), 무엇이 포함되는지(facts 3개), 바로 문의(버튼). 두 번째 줄 앵커 내비는 없다.

### 0-2. 히어로 공통 요소 (배치는 서비스마다 다름)
- eyebrow(영문) → h1(`cs-t-display`, 줄 ≤9자) → lead(`cs-t-lead`, 한 문장, 마침표 없음) → 가격 칩(`startingPrice(id)`: `head`는 `cs-t-price-sm`, 나머지 단위는 `cs-t-small`, ` · ` 단위 사이에서만 줄바꿈) → 버튼 2개(`상담 신청 ↓` → `#inquiry` primary, `가격 보기 ↓` → `#pricing` ghost) → facts 3개(`cs-t-small`, 세로선 구분, 모바일은 세로 쌓기).
- 간격: eyebrow→h1 `s5` · h1→lead `s5` · lead→가격 칩 `s6` · 칩→버튼 `s5` · 버튼→facts `s7`.
- 히어로 높이: ≥1024 `min(860px, calc(100svh - var(--cs-header-h)))`, 최소 600px. <768은 내용 높이(미디어가 아래로 내려간다).

### 0-3. 과정 공통 뼈대 (서비스 데이터가 문구만 바꾼다)
4단계 고정: ① 상담·자료 정리 → ② 기획안 전달(`함께 확인` = `기획안 수정 2회`) → ③ 제작·최종안 전달(`함께 확인` = `최종안 수정 1회`) → ④ 납품(`함께 확인` = 서비스별 한 줄). 수정 기준과 어긋나는 단계 설명을 쓰지 않는다.

### 0-4. 공통 FAQ 3개 (모든 서비스 마지막 3개, 문자열 그대로)
1. `수정은 몇 번까지 할 수 있나요?` — `기획안을 받은 뒤 2회, 최종안을 받은 뒤 1회 수정할 수 있습니다. 그 밖의 수정은 범위를 확인한 뒤 따로 안내합니다.`
2. `표시된 가격에 부가세가 포함되어 있나요?` — `포함되어 있지 않습니다. 표시한 금액은 모두 부가세 별도입니다.`
3. `여러 편을 정기적으로 맡길 수 있나요?` — `대량 제작과 정기 제작은 따로 견적을 드립니다. 편수와 일정을 알려주시면 범위를 안내합니다.`

### 0-5. 서비스별 차별화 요약 (벤치마크 SHARED + DIFFERENT 반영)

4. `납품` — `확정한 컷을 이미지 파일로 전달합니다.` / `컷별 이미지 확인`

### 1-7. scope
- 기본 포함: `12컷 또는 24컷 한 회` · `줄거리·대사·작화` · `기획안 수정 2회 · 최종안 수정 1회`

4. `이미 있는 웹툰도 모션코믹으로 만들 수 있나요?` — `네. 모션코믹 가격은 기존 웹툰을 영상화하는 기준입니다. 웹툰을 새로 그리는 비용은 따로입니다.`

## 2. 애니메이션 (WP-A) · `animation`

- <768: 문구 → 이미지(높이 58%, 위쪽 그라데이션).
- eyebrow `ANIMATION` / h1 `캐릭터가\n움직이는 장면` / lead `캐릭터와 배경을 설계하고 장면을 이어 30초와 60초 애니메이션으로 완성합니다`
- facts: `30초 · 60초` / `캐릭터·배경 설계` / `기획안 수정 2회`

### 2-2. types
eyebrow `WHAT WE MAKE` / h2 `이야기에 맞춰\n움직입니다`:
- `캐릭터 애니메이션` — `브랜드 캐릭터의 표정과 행동으로 이야기를 만듭니다.`
- `설명 애니메이션` — `보여주기 어려운 과정을 장면과 상황으로 풀어냅니다.`
- `숏폼 애니메이션` — `릴스와 쇼츠에 맞는 짧은 장면으로 구성합니다.`

### 2-3. signature 움직이기 전 확인 (client 섬 1개: 탭)
- eyebrow `BEFORE MOTION` / h2 `움직이기 전에\n장면을 맞춥니다` / lead `기획안 단계에서 이야기와 캐릭터, 장면 구성을 먼저 확인합니다`
- APG 탭 3개(`이야기` · `캐릭터` · `장면 구성`, 화살표·Home·End). 패널 = 본문 + CSS 일러스트(`aria-hidden`, 태그 `연출 예시`): 이야기 = 문장 카드 한 장, 캐릭터 = 원·둥근 사각형으로 만든 정면·측면 실루엣 두 개, 장면 구성 = 16:9 칸 4개의 콘티 틀(칸마다 번호). 패널 높이는 세 패널을 같은 grid 칸에 겹쳐 가장 긴 것에 맞춘다(P3 방식, 숨긴 패널은 heading 없는 사본).
  - `이야기` — `누가 무엇을 하는지 한 문장으로 정리하고 장면 순서를 나눕니다.`
  - `캐릭터` — `생김새와 표정, 움직임의 범위를 그림으로 먼저 정합니다.`
  - `장면 구성` — `장면마다 화면 구도와 길이를 정해 기획안에 담습니다.`
- JS가 없으면 세 패널이 모두 세로로 보인다.

### 2-4. works · pricing
- works: `layout="vertical"`(검토 빌드: 웹툰 기반 모션 2편).
- pricing: 30초 30만 · 60초 55만. 서비스 주석 없음.

### 2-5. process (h2 `장면을 확인하며\n만듭니다`)
1. `상담·자료 정리` — `알리고 싶은 내용과 쓰일 곳을 정리합니다.` / `핵심 메시지 확인`
