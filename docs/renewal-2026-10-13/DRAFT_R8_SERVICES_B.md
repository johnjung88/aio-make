# DRAFT R8 서비스 페이지 구성안 B-2b: 모션그래픽 · 브랜드 홍보 영상 · SNS 광고 영상

상태: 초안(코드 수정 없음). 사용자 승인 전에는 구현하지 않는다. 승인되면 B3b(모션그래픽)와 B3c(브랜드 홍보·SNS 광고)가 이 문서를 명세로 쓴다.
기준: `COMMON.md`, `PLAN_R8.md`, `BRIEF_R8.md`, `PRICING_FINAL_2026-10-14.md`, `lib/content-pricing.ts`(가격은 이 값 그대로, 이 문서에는 금액을 새로 쓰지 않고 화면 문구에 쓸 때만 `formatWon` 결과를 옮긴다).

## 0. 읽는 법과 공통 전제

### 0-1. 결정과 규칙 요약
- D1: 고객 소재 영상은 공개판에서 쓴다. 화면 문구(h1·h2·표·캡션·태그·alt)에는 고객명 문자열을 쓰지 않는다. 영상과 이미지 안에 찍힌 로고·제품은 그대로 둔다. 금지 문자열은 요프리, YoFree, 힐러넷, BWL, DR's Secret이고 맥스테크는 이 문서에서 같은 취급으로 쓰지 않는다.
- 대체 표기: 힐러넷 = `건강기능식품 원료 개발 기업`, 요프리 = `건강기능식품 브랜드`, 맥스테크 = `특장차 전문 기업`. 이름 없는 설명만 화면에 둔다.
- D2: 음악은 곡별 라이선스 원문을 저장한 무료 음원만 쓴다. Mixkit과 YouTube Audio Library는 쓰지 않는다. 자동재생은 무음이고 소리 켜기 버튼을 둔다.
- D3: 서비스마다 30초 서비스 영상 1편. 이 문서는 영상이 들어갈 자리의 요구만 정하고 컷표는 B-3이 만든다.
- 문체: 문장 끝 마침표 없음(현 사이트 관례, `lib/content-site/services/*.ts`와 `CS_COPY` 확인). 금지 문체는 `~을 통해`, `~에 대해`, `A가 아니라 B`, `A, B, C 없이`, 쉼표로 절을 이어 붙이는 문장, 과장.
- 가격 표시: 서비스 페이지 가격 블록은 `CsPricing`이 `contentPricing`에서 그린다. FAQ 답변에 금액을 쓸 때는 구현 시 `formatWon(contentPricing[...].amount)`로 조립한다(문자열 하드코딩 금지).

### 0-2. 현재 구조와 이번 구성안의 관계
현재 `service-landing.tsx` 순서는 Hero → Signature → (BeforePricing) → Pricing(+포함·별도) → Process → Works(검토판) → FAQ → Inquiry → Related다. 이 순서는 바꾸지 않는다. 서비스 모듈의 `Signature`는 이미 Fragment로 여러 `<section>`을 돌려줄 수 있으므로(모션그래픽 `landing.tsx`가 2개를 반환 중) 레지스트리 수정 없이 서비스 고유 섹션을 3~4개로 늘린다. 제작 과정은 별도 Signature를 만들지 않고 공통 `CsProcess`의 데이터(4단계 → 6단계)를 서비스 공정으로 바꾼다(공정 설명이 두 곳에 중복되지 않게).

## 1. 모션그래픽 (`motion-graphics`)

### 1-1. 현재 섹션 진단
- 히어로 미디어가 정지 이미지(`motion-hero-1`, 보라 유리 리본 PNG)라 모션 서비스인데 첫 화면에서 움직임이 보이지 않는다.
- 시그니처 `한 화면에서 다음 화면으로`는 정지 이미지 3장을 CSS로 넘기는 장면 전환이다. 문구도 "읽는 흐름을 만듭니다" 수준이라 무엇을 하는지 구체적인 정보가 없다.
- `BRAND CHARACTER` 3단계는 맞춤형 옵션 설명인데 서비스 전체의 두 번째 섹션으로 놓여 서비스의 중심처럼 읽힌다. 1단계 문장이 설정서 없는 구체 항목(말투·성격)을 말하고 있어 VERIFY_R6 R-6 권고(구체 항목 삭제)가 미해결이다.
- 제작 과정이 다른 5개 서비스와 같은 4단계(상담·기획안·제작·납품)라 모션그래픽 공정(스타일프레임, 컷별 비트시트, 사운드 싱크)이 보이지 않는다.
- 컷 단위 기획, 길이, 음악과 박자 같은 전문 정보가 한 곳에도 없어 "작업하다 만 것 같다"는 인상이 난다.

## 3. SNS 광고 영상 (`ad`)

### 3-1. 현재 섹션 진단
- 히어로가 AI 정지 이미지 9장과 "밤의 향기", "은은한 잔향" 같은 가상 광고 문구 카드를 흘려보내는 장식 레일이다(`aria-hidden`). 실제 광고 영상은 한 편도 재생되지 않는다.
- `VERTICAL EDIT`의 3장면은 AI 정지 이미지를 CSS로 넘기는 장면 전환이라 광고가 어떻게 짜이는지(첫 장면, 컷 길이, 자막, 소리) 알 수 없다.
- 광고에서 가장 중요한 첫 장면(훅) 설계가 서비스 어디에도 없다. 제작 과정도 `기획안 전달`에 묶여 있어 훅 설계, 컷 구성, 화면비 편집이 보이지 않는다.
- 9:16 규격과 기본 포함(자막·BGM)은 가격 블록에만 있고 화면에서 확인할 수 있는 근거(샘플)가 없다.
- 제품 하나에 광고 한 편이라는 기본 단위를 샘플로 보여주지 못한다.
