# 웹툰 페이지 단위·카피 변경 v16

2026-10-19 사용자 직접 지시로 웹툰의 가격 단위를 컷에서 12P·24P로 변경한다. 기존 금액은 유지한다. 1P 규격은 실제 원고 25P와 같은 가로 1,024px × 세로 1,536px, 세로형 2:3이다. 가격·희망 구성·JSON-LD와 상품 설명에 같은 단위를 적용한다. 기존 BRIEF_R8의 원문과 다른 서비스 조건은 보존한다.

- 이야기 형식과 12P·24P 중 분량을 정하고 줄거리를 씁니다
- 대사와 페이지 순서를 확인한 뒤 페이지별 완성 원고를 전달합니다
- 페이지별 이미지 확인
- 1P는 어떤 규격이고 분량은 어떻게 고르나요?
- 1P는 가로 1,024px × 세로 1,536px입니다. 12P·24P 중 필요한 분량을 고르고, 각 페이지의 장면과 대사를 함께 정합니다.

이 문서는 요청된 로컬 수정 기준이며 사용자 시각 확정·운영 배포·고객 채택을 뜻하지 않는다.
