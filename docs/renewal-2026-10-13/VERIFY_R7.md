## 5. FAIL 상세 (재현 방법·원인 추정)

### F-1 메인 설명문 줄바꿈: 마지막 줄이 짧다 (사용자 불만 직결)
- 재현: 검토판·공개판 `/` 폭 360·390·430에서 `#journey-marketing > .wj-lead`(2문장 각 2줄)와 `#journey-content > .wj-lead`. 문장 1의 둘째 줄이 "채널·…" 이전 몇 글자만 남아 폭의 23~32%. 측정 JSON `.qa/r7-verify/data/home1-{360,390,430}.json`의 `steps[*].leadLines`. 스크린샷 `shots/home-journey-marketing-390.png` 상단 설명문.
- 원인 추정: `.wj-lead { text-wrap: pretty; white-space: pre-line }`. Chrome의 `pretty`는 마지막 줄이 한 단어일 때만 줄이는 약한 규칙이라 BRIEF의 "마지막 줄 ≥ 40%"을 보장하지 못한다. 설명문 폭이 320~390이고 문장이 길어(약 34~40자) 2줄로 꺾이는 것이 문제.
- 권고: `text-wrap: balance`로 바꾸거나 문장을 줄인다. 430에서 마케팅 설명문은 줄 수 한도(3)도 초과(4줄). 담당 WP-1.

### F-2 컨텐츠 카드: 옆 카드 클릭이 먹지 않는다 (≥768px)
- 재현: `/` 768·1024·1440에서 `#journey-content`로 스크롤 → 옆 카드(`.wjc-card[data-pos="1"] .wjc-select`)를 클릭(실제 마우스, Playwright 클릭 둘 다) → 활성 카드가 바뀌지 않는다. 카드 중심에서 `document.elementFromPoint`가 `ul.wjc-track`을 돌려준다(25점 격자 모두 0/25). 하단 점 버튼·키보드·자동 넘김은 동작. 360~430의 가로 스크롤형 옆 카드 선택은 동작.
- 원인 추정: `.wjc-track`이 `transform-style: preserve-3d`이고 옆 카드가 뒤쪽 z(음수)로 밀려 있어, z=0 평면의 투명한 track 박스가 클릭을 먼저 받는다(`.wjc-card`·`.wjc-select`는 `pointer-events:auto`지만 가려진다). 활성 카드(z 앞쪽)의 링크는 정상.
- 권고: `.wjc-track { pointer-events:none }`, `.wjc-card { pointer-events:auto }` 후 재확인. 브리프 §2-5 "옆 카드 클릭" 항목. 담당 WP-3.

### F-3 푸터 서비스 링크가 붙는다 (768~1023px)
- 재현: `/content` 폭 768~1023에서 푸터 SERVICES 3번째 줄 "브랜드 홍보 영상SNS 광고 영상". 링크 사이 간격: 1줄 75.7px, 2줄 16.4px, **3줄 0px**(768·800·830·900·1000·1023 모두 동일). 스크린샷 `shots/ft-768.png`. 1024 이상(1열)과 767 이하(열 대칭 가운데)는 정상.
- 원인 추정: 2열 격자의 열 폭이 내용 폭(auto)이고 열 간격(`column-gap`)이 0이라 가장 긴 링크 "브랜드 홍보 영상"(103px)이 다음 열 시작과 맞닿는다.
- 권고: 열 간격 ≥ 24px 또는 `1fr 1fr`로 지정. 담당 WP-4.

### F-4 마케팅 번호·제목 y 중심 차이 2.8~3.4px
- 재현: `/` 폭 360~1440, `#journey-marketing .wj-mk-num`과 `.wj-mk-name`의 `getBoundingClientRect` 중심 y 차이(4-3).
- 원인 추정: `.wj-mk-step-head { align-items: baseline }`로 번호(14px)와 제목(20·22px)의 기준선을 맞춰서 번호 박스가 아래로 내려간다. 같은 줄이고 겹침·끊김은 없다. 기준을 "기준선 정렬"로 바꾸거나 `align-items:center`로 하면 ≤2px가 된다. 판단은 메인 몫. 담당 WP-2.

### F-5(경미) 푸터 높이 목표 초과(768 이상)
