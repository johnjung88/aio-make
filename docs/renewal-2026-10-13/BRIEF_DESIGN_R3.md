## R2 실제 화면에서 확인한 부족점

- 컨텐츠 첫 화면은 추상적인 유리 장식만 보여 실제 제작물의 증거가 없음
- 메인 첫 화면은 가상 대형 사무실과 전문가 주장을 앞세워 고객이 무엇을 받을지 알기 어려움
- 갤러리 웹툰 한 장의 좌우 빈 여백, 8단으로 쌓인 설명·칩·가격이 같은 시각 무게를 가짐
- 메인 소개 영상 891px, 5단계 약4960px, 페이지 약9800px로 공백과 반복 제목이 많음
- 고정 상담 패널이 첫 화면 CTA 및 카드 내용을 가림

확인 이미지: R2 final-content-top-1440/390, final-content-gallery-1440, final-main-services-1440, main-1440-top
로컬 벤치마킹 시안의 desktop-services, desktop-process, ad-desktop 실제 이미지와 인수 문서 확인

## 실행

A: 메인·컨텐츠 첫 화면에 서버에서 선택한 실제 작품과 공개 가능한 자체 예시를 시각 편집

메인은 웹사이트 화면+제품 영상 포스터로 컨텐츠/개발의 결과물을 첫 화면에서 설명
갤러리는 웹툰2장 펼침·세로영상 원비율·가로영상 원비율, 정보는 이름/용도/시작가/CTA 우선, 자세한 구성은 접기 안 보존
