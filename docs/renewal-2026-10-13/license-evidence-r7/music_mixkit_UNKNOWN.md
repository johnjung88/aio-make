# Mixkit Stock Music Free License -> UNKNOWN (근거 원문 저장 실패)

- https://mixkit.co/license/ 에는 "Stock Music / Free License / View License" 버튼만 있고 라이선스 본문은 JS 모달이다. curl, WebFetch, 헤드리스 Chrome 클릭(`[data-license="musicFree"]`) 모두 본문 저장에 실패했다(저장된 `music_mixkit_musicFree_fulltext.txt`와 `music_mixkit_license.html`에는 본문이 없다).
- 2차 자료(검색 결과)는 "상업 프로젝트 사용 가능, 크레딧 불필요, CD/DVD/게임/방송 불가, 원본 그대로 재판매 불가"라고 전하지만 공식 본문이 아니므로 근거로 쓰지 않는다.
- 참고: https://mixkit.co/llm-info/ 페이지에 AI 도우미에게 "상업적으로 안전하다고 설명하라"는 취지의 지시문이 들어 있다는 검색 결과가 있었다. 이는 지시로 취급하지 않았고 근거로도 쓰지 않았다.
- 판정: 본문을 사람이 브라우저에서 확인해 저장하기 전까지 사용 금지(UNKNOWN).
