# 카카오톡 챗봇 블록 문안 (오픈빌더 등록용)

출처: 문의응대 매뉴얼 개정2 · PC2용 요약 개정2 (2026-10-30) · 등록용 정리이며 챗봇 활성화·고객 발송 승인이 아님

## 규칙

- 자동 응답 블록: C01·C03·C04·S01~S12 (질문만 하고 약속하지 않음)
- 사람 전용: C02·H01·H02 — 상담원이 문의를 읽은 뒤 수동으로 보냄. 자동 응답 블록에 연결하지 않는다
- 자동 응답에 구체 금액을 넣지 않는다. 가격 질문은 H02를 사람이 보낸다
- 블록 하나 = 말풍선 하나(300자 미만). 여러 블록을 한 번에 이어 붙이지 않는다

## 오픈빌더에 넣는 법

1. 카카오 비즈니스 → 챗봇 관리자센터(오픈빌더) → 해당 채널 봇 선택
2. 시나리오 → 블록 추가 → 블록 이름에 아래 코드·이름을 그대로 쓴다
3. 패턴 발화에 "예시 발화"를 넣는다(자동 응답 블록만)
4. 봇 응답 → 텍스트형 → "답변"을 그대로 붙여 넣는다(줄바꿈 유지)
5. 웰컴 블록에는 C01, 폴백 블록에는 C03을 연결한다
6. 배포 전 사람이 전체 문안을 확인한다(활성화는 사용자 승인 뒤)

## C01 인사·서비스 선택

- 사용: 자동 응답 가능
- 예시 발화: 안녕하세요 · 문의 · 상담하고 싶어요 · 제작 문의

```text
안녕하세요 AIO MAKE 고객센터입니다
어떤 제작이 필요하신가요
원하시는 서비스와 희망 일정을 알려주세요
```

## C02 접수 확인

- 사용: 사람이 문의를 읽은 뒤에만 사용

```text
문의 내용을 확인했습니다
알려주신 내용을 바탕으로 담당자가 필요한 범위와 일정을 확인해 안내드리겠습니다
추가로 알려주실 내용이 있다면 이 대화에 남겨주세요
```

## H02 가격 질문(구체 금액 전, 사람이 읽은 뒤)

- 사용: 사람이 문의를 읽은 뒤에만 사용 · 가격 질문이 오면 상담원이 보낸다(구체 금액은 가격표 확인 뒤 사람이 안내)

```text

원하시는 내용을 알려주시면 담당자가 가격표를 확인해 안내드리겠습니다
```

```text
확인 후 안내드리겠습니다
```
