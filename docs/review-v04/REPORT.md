## GA4의 현재 상태와 다음 행동

로그인된 Google Analytics 화면에서 AIO-MAKE 속성 **536780274**와 통계 수집을 직접 확인했다. 속성의 접근 목록에는 서버 조회 계정이 없었고, 로컬 설정에도 조회용 인증이 없었다. 따라서 **측정 태그 존재·Google 화면의 통계 확인·대시보드 서버 조회 성공은 서로 다른 상태**다.

`AIO MAKE Analytics` 전용 Google 프로젝트 생성 양식까지만 준비했다. 만들기, API 활성화, 조회 계정·키 생성, GA 속성 권한 부여는 실행하지 않았다. 사용자에게 조회 전용 연결 승인을 요청했다. [GA4-CONNECTION.md](GA4-CONNECTION.md)에 구체적 후속 절차와 실제 성공 기준을 기록했다.

운영 DB·계정·권한·배포는 변경하지 않았다. 원본 후보에 기록된 Supabase/Vercel 상태는 이번에 재확인하지 않았으므로 최신 상태로 단정하지 않는다. 실제 DB 연결·배포 전 점검은 기존 `docs/renewal/RELEASE.md`를 이어서 적용한다.

## 인계

현재 로컬 미리보기는 `http://127.0.0.1:3100/`, 관리자 `/admin`. 시험 DB를 연결했던 캡처의 숫자는 실제 사업 수치가 아니다. 최종 기본 환경은 DB·GA 미연결을 사실대로 표시한다.

가이드 생성 스크립트를 다시 실행하면 JSX의 수동 개선이 덮일 수 있으므로 이번 변경과 먼저 대조한다. 원본 HTML과 기존 승인 자료는 수정하지 않았다. 다음 실행자는 Google 읽기 연결을 끝낸 뒤 실제 응답·동일 기간 비교·오류 복구를 확인하고, 운영 반영 여부를 별도로 기록해야 한다.
