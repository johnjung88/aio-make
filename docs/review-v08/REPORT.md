## 반영

- 마케팅·개발 상담 문구의 마지막 마침표를 제거하고 요청한 위치에서 두 줄로 분리했다.
- 통합 마케팅의 향수 화보를 유입·매출·문의 흐름을 표현한 분석 이미지로 교체했다. 메인 모션에는 실제 성과 수치가 아닌 연출 예시의 두 그래프가 점진적으로 그려지게 했다.
- SEO·AEO·GEO 이미지를 사이트 정보에서 검색 결과와 AI 답변으로 이어지는 이미지로 교체했다. 소개 문장을 사이트 구조·고객 질문·소스 또는 CMS 적용 작업으로 구체화하고, 모션 화면에는 세 영역의 역할을 표시했다.
- 개발의 웹사이트 제작 예시 이미지를 PC·모바일 반응형 화면으로, 업무 자동화 이미지를 입력·처리·결과 흐름으로 교체했다. 업무 자동화 메인 모션에는 단계 연결선이 움직이는 그래픽을 추가했다.
- 새 이미지 4장은 `public/creative-v08/`에 보존하고 기존 `public/creative-v06/` 원본은 유지했다. 해당 서비스만 v08을 참조한다.
