## 시그니처 계약

HTML 버튼 입력 → 단일 선택 상태 갱신 → 현재 결과 카드·설명·소재 동시 렌더링
선택 버튼에 포커스를 유지하고 aria-pressed, 짧은 role=status로 상태를 전달한다
자동 재생·RAF·타이머·WebGL·외부 API를 도입하지 않아 hidden·화면 이탈 후 계속 도는 작업이 없다
감소 모션에서는 전환 효과를 제거한다 JS가 꺼지면 noscript에 전체 단계 설명을 제공한다
이미지 실패는 설명과 재시도 버튼으로 대체한다 일반 상담 링크는 항상 제공한다
상태는 페이지 안에서만 유지하며 저장·접수·전환 이벤트를 발생시키지 않는다

## 3-SET 검토

W-R1a의 기존 목소리를 유지하는 카피 B 유형으로 검토한다 제공 조건을 새로 만들지 않는다
ui-ux-pro-max·frontend-design 스킬은 현재 설치에서 발견되지 않아 호출하지 못했다
MASTER·WORKFLOW의 카피·디자이너 관점을 자체 적용하고 정렬·행간·모바일·포커스를 검증한다

## 공개·문의 보존

작업 공개 조건과 필터, 서비스 문의 쿼리, InquiryBridge, 유입 보존, 전환 API와 개인정보 동의 흐름을 유지한다
실제 문의 제출·외부 전환 수신·push·PR·배포는 이 작업에서 실행하지 않는다
